Prices are live BTC-USD, ETH-USD and XRP-USD mids from Coinbase's public feed; balances are test USDC on Base Sepolia, which has no value. The desk prices each contract with a lognormal model at a volatility the desk sets itself: by default a steady 24-hour at-the-money implied volatility interpolated between the Deribit option expiries either side, with Deribit's 30-day DVOL index or 5-hour realized volatility as alternatives. If Deribit can't be reached, implied pricing uses realized volatility scaled by the average implied-to-realized ratio seen so far. Real returns have fatter tails and changing volatility than the model assumes, so its probabilities can be wrong in either direction. Contracts settle at expiry even if this page is closed. If the price feed is down at expiry, the contract is voided and the stake refunded.
